# Pregunta del día

**Spanish conversation questions, drawn from a deck of cards.**

Pregunta del día ("question of the day") is a small app for practising Spanish. Pick a deck, draw the top card, and it flips over to show a conversation question to answer out loud, write about, or bring to your next language exchange. If you get stuck, each card also has an English translation, a few useful words and a sentence starter.

It runs as an installable web app (PWA) that works offline. The deck is also a self-contained [Preact](https://preactjs.com) component you can drop into your own site.

## Features

- **Themed decks:** Día a día, Comida, Sobre ti, Relaciones, Trabajo y estudios, Tiempo libre, Cultura y viajes, Opiniones y debate and Imagina, plus **Todas**, which combines them. Pick one from the row of card packs along the bottom; each deck has its own card-back colour (Todas keeps the green). A card drawn from any deck is gone from every deck it's in until you put it back.
- **Your own shuffled deck.** Draw as many cards as you like, shuffle whenever you like, and every card comes up once before you start again.
- **History:** swipe back through every card you've drawn, newest first, as full cards with their help. Put any card back into the deck, or all of them at once. When a deck runs out, one tap puts its cards back and shuffles.
- **Streak:** counts the days in a row you've drawn a card. Everything is stored in your browser only; there's no account and no server.
- **Help when you need it:** an English translation, key vocabulary and a sentence starter, shown only when you ask.
- **Listen:** reads the question aloud with your browser's built-in Spanish voice.
- **Feels like a real deck:** a hand-like draw-and-flip animation, a riffle-and-bridge shuffle, and you can turn the card back over and face up again.
- **Comfortable to use:** light and dark mode (follows your system setting, with a toggle), full keyboard support, and reduced motion respected.
- **Questions from beginner to advanced:** levels A1–C1, written in neutral Spanish (where words differ by region, the vocabulary gives both). Growing towards 3,000.

## Getting started

The quickest way to run it is with Docker, so you don't need Node installed:

```bash
make dev       # dev server at http://localhost:5173
make build     # type-check and build the PWA into dist/
make preview   # build, then serve dist/ at http://localhost:4173
```

These wrap `docker compose`. Your source folder is mounted into the container, and `node_modules` lives in a Docker volume. To start fresh, run `docker compose down -v`.

If you'd rather use Node directly (version 20 or newer):

```bash
npm install
npm run dev
```

The service worker is only generated by a production build, so use `make preview` (or `npm run build && npm run preview`) to test offline use and installing the app.

## Checks

Every pull request runs the CI workflow: unit tests for the deck logic and checks on the questions (`make test` or `npm test`), a type-checked production build, then [Lighthouse](https://github.com/GoogleChrome/lighthouse-ci) three times against it (mobile, throttled). The Lighthouse job fails if the median score drops below 90 for performance, or below 100 for accessibility, best practices or SEO. The thresholds are in [`lighthouserc.json`](lighthouserc.json), and the full reports are saved with each run. To run the same audit locally after a build:

```bash
npx @lhci/cli@0.14.0 autorun
```

hashed files in `/assets/` are cached forever.

## Writing your own deck

The questions live in [`src/PreguntaDelDia/questions/`](src/PreguntaDelDia/questions), one JSON file per deck, one card per line. Each card looks like this:

```json
{
  "id": "q0032",
  "es": "¿Qué te hace reír siempre?",
  "en": "What always makes you laugh?",
  "level": "B1",
  "category": "Personalidad",
  "vocab": [["me hace gracia", "I find it funny"], ["el chiste", "joke"]],
  "starter": "Siempre me hace reír…"
}
```

- `id` is unique and permanent. Each deck takes new ids from its own range in [`scripts/question-ranges.json`](scripts/question-ranges.json); `npm run stats` (or `make stats`) prints the next one for each deck, along with how many cards each deck has at each level against the targets.
- To add cards in bulk, see [`docs/writing-questions.md`](docs/writing-questions.md): the writing standard, and `scripts/add_questions.py`, which appends a batch with the right ids.
- `level` is one of A1, A2, B1, B2, C1. `category` must be one of its deck's categories.
- `vocab` has 2–4 pairs and `starter` is required for the built-in deck (both are optional in your own `questions`).
- Questions are punctuated `¿…?` (the `¿` can open mid-sentence: "Si pudieras…, ¿cuál…?"); prompts such as "Cuéntame…" end in a full stop.

Edit the list, or pass your own with the `questions` prop. Each person's deck is saved by card `id`, so you can add, remove and edit questions freely: new cards are shuffled into everyone's deck, and removed ones disappear from it. Never reuse or change an id, or someone's history will point at the wrong card.

Decks are defined in [`src/PreguntaDelDia/decks.ts`](src/PreguntaDelDia/decks.ts) as lists of categories:

```ts
{ id: 'imagina', name: 'Imagina', categories: ['Hipótesis'], back: ['#4650a0', '#272d68'] }
```

`back` is the deck's card-back colour, the light and dark ends of the gradient behind the shared pattern. It's optional; without it the deck uses the theme's `--pdd-back-1` and `--pdd-back-2`, as Todas does.

Every category must belong to exactly one deck, and each deck's cards go in the file named after its id. `npm test` checks all of this, along with ids, fields, punctuation, duplicates, and that the cream text on each card back has at least 4.5:1 contrast. Pass your own decks with the `decks` prop; **Todas** is always added.

## Using the component in your own site

`src/PreguntaDelDia/` is self-contained: the component, its styles, the deck and the date logic. It works in any Preact or Vite project. Here's an example for [Astro](https://astro.build):

1. Add Preact to your site:

   ```bash
   npx astro add preact
   ```

2. Copy `src/PreguntaDelDia/` into your project, for example to `src/components/PreguntaDelDia/`.

3. Use it on a page:

   ```astro
   ---
   import PreguntaDelDia from '../components/PreguntaDelDia';
   ---
   <PreguntaDelDia client:load />
   ```

   The saved deck is only read in the browser. The server renders a face-down deck, so nothing mismatches when the page loads. `client:visible` also works.

### Props

| Prop         | Default              | Purpose                                                 |
|--------------|----------------------|---------------------------------------------------------|
| `questions`    | built-in questions   | Your own `Question[]`; each needs a unique, permanent `id` |
| `decks`        | built-in decks       | Your own `Deck[]` (lists of categories); **Todas** is always added |
| `storageKey`   | `'pregunta-del-dia'` | `localStorage` key; change it if you run several decks on one site |
| `title`        | `'Pregunta del día'` | Heading                                                    |
| `headingLevel` | `2`                  | Heading level for the title; use `1` if the deck is the whole page |

### Theming

All classes start with `.pdd`, and the look is controlled by CSS custom properties. Colours use `light-dark()`, so one value covers both themes:

```css
.pdd {
  --pdd-back-1: #1f6a51;                          /* card back gradient */
  --pdd-back-2: #123f33;
  --pdd-back-frame: light-dark(#f6eedb, #e9dfc6); /* card border */
  --pdd-back-line: #f6eedb;                       /* inner line and emblem ring */
  --pdd-accent: light-dark(#1b6b4f, #74d1a4);
  --pdd-font-display: 'Your Display Font', sans-serif;
  --pdd-font-body: 'Your Body Font', sans-serif;
}
```

Text that sits on your page rather than on a card (the title, date and footer) uses `--pdd-page-text` and `--pdd-page-muted`. By default these match the card text. Set them separately if your page background stays the same in both themes.

The deck follows the system light/dark setting. To force a theme, set `data-theme="light"` or `data-theme="dark"` on `<html>` (or on the component itself). If your site's theme toggle already sets `data-theme` on `<html>`, the deck follows it.

### Installable app inside Astro

To make your Astro site (or one route of it) installable, use [`@vite-pwa/astro`](https://vite-pwa-org.netlify.app/frameworks/astro), which wraps the same plugin this project uses:

```bash
npx astro add @vite-pwa/astro
```

```js
// astro.config.mjs
import AstroPWA from '@vite-pwa/astro';
export default defineConfig({
  integrations: [
    preact(),
    AstroPWA({
      registerType: 'autoUpdate',
      manifest: { /* copy from vite.config.ts; set start_url/scope to your route, e.g. '/pregunta/' */ },
      workbox: { navigateFallback: '/pregunta/', globPatterns: ['**/*.{css,js,html,svg,png,woff2}'] },
    }),
  ],
});
```

Copy `public/icons/` into your site's `public/` folder. Then add `<link rel="manifest" href="/manifest.webmanifest">` to your layout and register the service worker (`import { registerSW } from 'virtual:pwa-register'`). Alternatively, host this project's standalone build on its own subdomain or path.

## Project structure

```
src/PreguntaDelDia/     the reusable component
  index.tsx             component
  DeckTray.tsx          the row of deck packs along the bottom
  CardFace.tsx          a card's face: question, buttons and help (table and history)
  History.tsx           the history: drawn cards to swipe through and put back
  questions/            the questions, one JSON file per deck
  questions.ts          combines them; the Question type
  decks.ts              themed decks (lists of categories)
  deck.ts               drawing, shuffling and returning cards (pure functions)
  storage.ts            saving the deck (localStorage), streak
  shuffle.ts            the riffle-and-bridge animation
  daily.ts              local day numbers (for the streak)
  styles.css            styles, themed with CSS custom properties
src/main.tsx            entry point for the standalone app
src/ThemeToggle.tsx     light/dark toggle (standalone app only)
tests/                  unit tests for the deck logic, checks on the questions
src/app.css             page background, font and toggle styles (standalone app only)
src/assets/fonts/       self-hosted font subset and its licence
public/icons/           app icons
scripts/make_icons.py   icon generator (run with `make icons`)
scripts/subset_font.py  font subsetter (run with `make font`)
scripts/question-stats.mjs  progress per deck and level (`make stats`)
scripts/add_questions.py    appends a batch of cards to a deck (see docs/writing-questions.md)
vite.config.ts          Vite and PWA setup
firebase.json           Firebase Hosting site and caching rules
Dockerfile, compose.yaml, Makefile   Docker-based dev and build
```
